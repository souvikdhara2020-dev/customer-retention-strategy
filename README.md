# Customer Retention Strategy Analysis

## Project Overview
This project analyzes customer purchasing behavior, loyalty, promotions, and revenue patterns using Python, SQL, and data visualization techniques.

The goal is to identify:
- High-value customers
- Promotion dependency
- Loyalty trends
- Revenue-generating product categories
- Purchase frequency behavior

## Key Insights

- Clothing category generated the highest revenue.
- Footwear category had the highest average purchase amount.
- High-value customers showed the highest promotion dependency.
- Clothing customers had the highest loyalty score.
- Quarterly purchase frequency was the most common behavior.
